## 二、本轮新发现并修复

### 1. 耗材库存台账显示材料 UUID

- 现象：库存台账「材料ID」列是 `8f2e...`。
- 根因：`/inventory` 返回 `material_id`，前端直接渲染。
- 修复：用材料档案列表映射为「编号 / 名称」。

### 2. 反馈渠道显示英文

- 现象：`mobile` / `desk`。
- 修复：`mobile→移动端`、`desk→后台`。

### 3. 运送详情动作按钮英文

- 现象：`receive → assigned`、`complete → done`。
- 修复：统一 `actionLabel()`；必填字段标题走 `FIELD_LABEL`；
  `assignee/carrier` 改为师傅下拉。

### 4. 巡检详情动作按钮英文

- 现象：`checkin → in_progress`、`exception → exception`。
- 修复：`actionLabel()` + 巡检动作中文字典（签到/异常上报/完成等）。

### 5. 通用业务流动作按钮英文

- 现象：`t.event → t.to`。
- 修复：`actionLabel()`。

### 6. 巡更状态英文

- 现象：`pending / in_progress / done / missed`。
- 修复：待执行 / 执行中 / 已完成 / 已漏检。

### 7. 负责人字段是自由文本 / 裸工号

涉及：巡检、巡更、运送、通用业务流。

- 现象：输入框让管理员手填 worker 账号名，列表显示 `HQ016`。
- 修复：统一 `/workers` 映射 + 师傅下拉；列表/详情显示姓名。

### 8. 多个业务表单只有 placeholder、没有字段标题

已补 `FieldLabel`：

```text
资产管理：新建/编辑、调拨、故障报修、维保
耗材管理：材料建档、出入库
巡检管理：新建巡检单
巡检计划：新建计划
运送管理：新建运送单
应急预案：新建/编辑预案
巡更管理：派发巡更任务
需求反馈：回复
志愿者：发布活动
人员管理：开通人员、新建/编辑人员
```
