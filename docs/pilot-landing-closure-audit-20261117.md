# pilot「部署 → 落地应用」全模块闭环审计报告（2026-11-17）

> 范围：方案 B（全模块 + 平台端 + 小程序），只出建议，不实施优化。
> 纪律：pilot 真实业务数据只读；写操作全部落 `uat-*` 隔离租户并清理；本轮未改代码/配置。

## 1. 结论

- **代码与主流程层面基本闭环**：16 模块 API 闭环 16/16、闭环专项 18/18、现场真实性 10/10、志愿者 NO_GAPS、效率 NO_GAPS、平台 NO_GAPS、完整业务链（含评价）PASS、平台+时间 70/70。
- **“部署 → 落地应用”仍有断点**，主要集中在运维、内容配置、平台 UI 与外部通知，而不是核心业务代码：
  - pilot 数据库/上传没有纳入每日自动备份（现仅备份主站 `youfu`）；
  - 迁移台账缺 116/117/118（schema 已生效，但 `_migrations` 未登记）；
  - pilot PC 端 `/monitor`、`/transport` 被 `PILOT_MODE` 重定向到工作台；
  - 微信通知 6 条全部 `delivered=false`（站内信 8 条正常）；
  - 主数据/运营内容稀疏：0 耗材、0 应急预案、0 术语、0 工单模板、0 反馈、1 资产、1 设备、1 张已作废结算；
  - 平台模板市场 0 条且 UI 无“新建官方模板”；平台位置/报修人字典只支持新增/查看，编辑/停用未实现；
  - 巡检计划处于“已暂停”，2 条巡检已逾期，自动生成未运行；
  - `pilot-tenant-b` 测试租户仍在平台监察中，平台审计含历史 e2e 账号记录。

## 2. 审计方法

1. 静态：336 个后端 handler、41 个 PC 页面、41 个小程序页面、菜单权限 38 列、工作流 14 态/32 边。
2. 配置：pilot 租户/账号/角色/部门/字典/流程/派单/通知/系统配置快照。
3. 动态：UAT 租户跑模块闭环与跨模块链；PC 27 路由 + 关键详情抽屉；平台 7 个 Tab；小程序 88 个 JS 语法 + 页面完整性。
4. 运维：服务、迁移台账、调度器、备份、通知投递、审计。

## 6. 优化建议（只出建议，不做）

### 6.1 立即（0.5–1 天/项）

1. **pilot 纳入每日备份**：独立 `backup_pilot.sh`（DB + uploads），保留 14/30 天，异地/对象存储一份，补一次恢复演练。
2. **修复迁移台账**：核对 116/117/118 schema 后补登 `_migrations`；增加“schema 与台账一致性”门禁。
3. **微信通知排查**：核对 openid、订阅模板授权、模板 ID、发送返回码；在 pilot 真机复验一条真实派单，并把失败原因展示在通知详情。
4. **保存巡检定位策略**：把 `inspection_geo_policy` 从“新键未保存”落库，明确 off/warn/block。
5. **处理测试租户与审计噪音**：确认 `pilot-tenant-b` 去留；平台审计过滤/标记 e2e 记录。

### 6.2 短期（2–4 天）

6. **主数据落地包**：耗材/库存、应急预案、术语、工单模板各至少 1–2 条真实可用数据；否则相关页面与看板长期空白。
7. **平台模板市场**：补官方模板 seed 或“新建模板”入口；否则模板应用/效果回写无内容可运营。
8. **平台字典编辑/停用**：补 PUT/DELETE 端点与 UI（位置、报修人），与基础数据“停用优先”口径一致。
9. **PC 巡更执行面**：任务详情 + 管理端手工补签（`via=manual`），与 MP 扫码形成双通道。
10. **工单详情本地化**：把 `reporter_name`、`source`、`business_type`、`location` 纳入共享标签/格式化，禁用原始 JSON dump。
11. **空态/开通向导**：0 数据模块给出“去建档/去配置”的下一步，而不是只显示“暂无数据”。

### 6.3 中期（1–2 周）

12. **监控/运送产品决策**：若 pilot 需要，去掉 `PILOT_MODE` 重定向并纳入菜单/权限；若不需要，在导航与文档中明确“pilot 不启用”，避免用户找不到入口。
13. **小程序 CI**：用 `miniprogram-ci` + 私钥在 CI 生成预览/上传，替代人工登录开发者工具。
14. **运维可观测**：调度器心跳、备份成功/失败告警、通知送达率、慢查询/连接池指标。
15. **数据质量**：公开报修“位置=待核实”的补全策略；主数据导入校验与重复检测。
