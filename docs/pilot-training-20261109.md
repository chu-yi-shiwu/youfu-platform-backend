# 试点培训与操作手册（2026-11-09）

## 1. 上线前配置（管理员）

1. 基础数据 → 部门
   - 维护总务科/维修组/保洁组/安保组；
   - 设置一个默认部门。
2. 基础数据 → 部门路由规则
   - 例：描述包含“漏水” → 维修组；业务类型 cleaning → 保洁组。
3. 基础数据 → 位置 / 问题目录 / 人员
   - 人员填所属部门、技能标签；
   - 可用 `import-pilot-master.mjs` 批量导入（见 `docs/pilot-master-import-20261109.md`）。
4. 系统管理 → 租户品牌信息
5. 账号
   - 运营：operator
   - 师傅：worker，并绑定小程序
6. 小程序
   - 师傅进入工作台 → 「开启通知」→ 允许订阅 → 自检 errcode:0。

## 2. 运营（PC）

### 建单

1. 工单申报
2. 选择业务类型、问题目录、位置
3. 填写标题、描述、报修人
4. 部门可留空（系统自动识别）
5. 提交

### 派单/改派

- 自动派单失败时，在工单详情选择「改派」→ 选师傅。
- 部门不对时用「改部门」，不要重建单。

### 关闭/评价

- 师傅完成后，运营核对 → 关闭；
- 关闭后评价 1–5 分；
- 评价后工作台满意度/已评价数更新。

### 日常工作台

- 待处理工单：今日要处理的单
- 超时待办：已超期望完成时间
- 今日新增
- 工单列表支持状态、部门筛选和导出

## 3. 师傅（小程序）

1. 微信打开小程序 → 登录（首次绑定微信）
2. 工作台只看本人任务
3. 点任务 → 接单/开始处理
4. 到场 → 处理 → 完成
5. 需要时拍照/语音留痕
6. 完成前确认现场已处理

注意：

- 师傅端不出现部门、派单、结算等运营字段；
- 弱网提交失败会明确提示，重试即可；
- 不要用 PC 登录师傅账号（会被拒绝）。

## 4. 试点期每日检查

- 工作台：待办/超时/今日新增是否异常
- 工单列表：是否有部门为空或归属错误
- 通知：师傅是否收到派单提醒
- 小程序：版本号是否为最新体验版
- 备份：当日备份是否成功
- 问题记录：统一记录到「需求反馈中心」或试点群
