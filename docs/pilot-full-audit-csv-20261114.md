## 一、CSV 导入/导出整改

### 1. 统一为中文表头（兼容旧英文表头）

| 模块 | 导出表头 | 导入兼容 |
| --- | --- | --- |
| 资产 | 资产编号 / 资产名称 / 型号 / 拼音 / 位置 / 状态 / 序列号 / 财务分类 / 购置金额 / 供应商 / 购置日期 | 中文表头 + 旧英文 key |
| 耗材 | 材料编号 / 材料名称 / 类别 / 规格 / 单位 / 单价 / 文档说明 / 启用 | 中文 + 英文 |
| 设备 | 设备名称 / 编号 / 类型 / 厂商 / 型号 / 序列号 / 安装位置 / 状态 / 购置日期 / 金额 / 责任人 / 备注 | 中文 + 英文；类型/厂商按名称或编码解析 |
| 基础数据 | 使用字段中文标签（部门名称/编码/备注等） | 中文 + 英文；区域上级/默认报修人按名称解析 |
| 反馈 | 提交时间 / 类型 / 内容 / 评分 / 状态 / 渠道 / 回复内容 / 回复时间 | 仅导出 |
| 巡检 | 任务标题 / 类型 / 状态 / 负责人 / 点位 / 计划/完成/创建时间 / 检查项数量 / 合格 / 不合格 | 仅导出 |
| 结算 | 单号 / 分类 / 价目 / 数量 / 金额 / 备注 / 工单号（原已中文） | — |
| 工单/统计 | 前端列定义中文表头（原已中文） | — |

### 2. 值的人话化

- 状态：`in_use → 在用`、`repairing → 维修中`、`pending → 待执行` 等；
- 渠道：`mobile → 移动端`、`desk → 后台`；
- 布尔：`true/false → 是/否`；
- 日期：`2025-05-31T16:00:00.000Z → 2025-06-01`（日期字段）或 `YYYY-MM-DD HH:mm:ss`（时间字段）；
- 设备类型/厂商：UUID → 名称；导入支持按名称/编码反查；
- 巡检负责人：UUID → 师傅姓名（无档案时保留原值）。

### 3. 导入健壮性

- 单次最多 2000 行，超限 400，不静默截断；
- 逐行校验，返回 `inserted / skipped / errors[]`；
- 缺必填、类型/厂商不存在、写入失败会记录行号与原因；
- 前端导入结果提示“已导入 X 条，跳过 Y 条：原因”；
- 公式注入防护沿用 `csvEscape`。
