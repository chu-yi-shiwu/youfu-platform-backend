# 小程序端布局优化实施记录（2026-11-14）

> 决策：方向 E 全做；工作台=仪表盘；工单详情底部固定主操作；管理端新增待办 Tab。
> 本轮仅改小程序（`youfu_mp_pilot`），后端/PC 无需同步变更。

## 1. IA 收敛

- **工作台改为仪表盘**：移除「在办/已完成」任务列表与 Tab，只保留档案、统计、抢单、任务入口、工具。
  任务清单统一收口到「待办」（`workbench.wxml`、`workbench.js`）。
- **工具入口唯一**：
  - 工作台保留「通知 / 扫资产」；
  - 巡更/陪检/志愿活动收口到「我的 → 现场工具」；
  - 通知对 worker 从工作台进入，对管理角色保留在「我的」（`profile.wxml` 按角色显示）。
- **“我的”入口唯一**：移除工作台身份卡、调度台头部、受理台头部、总览模块列表里的“我的/个人中心”，只保留底部导航。
- **个人中心「进入工作台」**：仅居民/非员工显示；员工底部导航已有工作台/总览。

## 2. 现场效率

- **工单详情底部固定操作条**：
  - 接单/到场/完成/取消等状态动作常驻底部，安全区适配；
  - 页面内容增加底部留白，避免遮挡；
  - AI 处置建议默认折叠，点击展开；
  - 「更换件（仅记录）」与「耗材领用（扣库存）」合并为一个「用料」入口，动作面板分流；
  - 已领用清单保留在页面内。
- **巡检执行底部固定操作条**：
  - 主操作固定为「完成巡检」；
  - 保存检查结果/拍照并加水印/标记异常并转工单收进「更多」动作面板；
  - 页面底部留白，避免遮挡。

  - reviewer：待复核；
  - operator/dispatcher：待派/待抢单、待处理预警；

- `tab-shell` 为 admin/operator/dispatcher/reviewer 增加「待办」第三格，并显示总数角标（60s 缓存 + 请求合并）。
- 待办计数复用现有接口，无新增后端端点。
