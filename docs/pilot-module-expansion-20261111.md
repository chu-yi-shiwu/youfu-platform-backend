# pilot 功能模块开放说明（2026-11-11）

## 变更

pilot 不再只保留报修闭环，改为开放主站除以下两项外的全部模块：

- 网管监控 `/monitor`
- 运送管理 `/transport`

已开放：

```text
结算管理 / 巡检管理 / 巡检计划 / 巡更管理 / 志愿者活动
资产管理 / 耗材管理 / 设备管理 / 应急预案
数据大屏 / 统计分析 / 自适应优化
体验用户 / 手机端 / 移动入口
```

原有模块继续保留：

```text
首页 / 工作台、工单申报、工单管理、业务规则设置、派单规则、
术语表、系统配置、基础数据、系统管理、需求反馈中心
```

## 实现

- `src/layouts/MainLayout.tsx`
  - `PILOT_HIDDEN` 从原来的 15 项收敛为 `/monitor`、`/transport` 两项。
- `src/pages/Dashboard.tsx`
  - 试点也加载业务看板/优化数据；
  - 巡检、应急预案、资产卡片恢复显示；
  - 运送任务卡片在试点仍隐藏；
  - 优化飞轮对 admin 恢复显示。
- `src/App.tsx`
  - pilot 直接访问 `/monitor`、`/transport` 会重定向到 `/dashboard`，避免绕过菜单。

```text
  - 菜单不存在：网管监控、运送管理
  - 直接访问 /monitor、/transport → /dashboard
  - 各开放模块页面可打开，不白屏
```

## 注意事项

1. 菜单仍受 RBAC 权限点控制：admin 全量可见；operator 等角色按权限矩阵显示。
2. 模块页面已可打开，但 pilot 库中这些模块的业务数据可能为空，页面会显示空态；需要时再导入/配置。
3. 后端路由与表结构原本就在，无需新增迁移。
4. 网管监控、运送管理仅在前端 pilot 隐藏/重定向；后端接口仍保留，供主站使用。
