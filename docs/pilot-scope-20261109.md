# 单租户试点范围与验收清单（2026-11-09）

试点租户：`zixing-hospital`（资兴市人民医院）
渠道：PC 管理端 + 微信小程序；H5 不进入试点。

## 1. 角色与渠道

| 角色 | 渠道 | 可见范围 | 主要动作 |
| --- | --- | --- | --- |
| admin | PC | 全租户 | 配置、账号、部门、路由规则、兜底处理 |
| operator | PC | 全租户 | 建单、派单/改派、改部门、关闭、评价、导出 |
| worker | 小程序 | 仅本人任务 | 接单、到场、处理、完成、上传照片/语音 |

渠道强制：worker + PC → 403；operator + 小程序 → 403。

## 2. 纳入试点的闭环

1. 运营/公开端建单
2. 部门自动识别（显式 > 路由规则 > 默认部门）
3. 自动派单或人工派单/抢单
4. 师傅小程序接单 → 到场 → 完成
5. 运营关闭 → 评价
6. 工作台统计、工单列表、详情、时间线
7. 通知（站内信；微信订阅消息为 P1）
8. 基础数据：部门、位置、问题目录、人员、路由规则

## 3. 暂不纳入

- 结算管理
- 巡检 / 巡更
- 运送
- 资产 / 耗材 / 设备
- 应急预案 / 网管监控
- 志愿者
- 数据大屏 / 统计分析 / 自适应优化
- AI 助理
- H5 移动端

`/pilot/` 构建已通过 `VITE_PILOT_MODE=1` 隐藏上述菜单和工作台看板。

## 4. 验收清单

### 功能

- [ ] operator 不选部门建单，系统自动归属
- [ ] 无规则命中时落默认部门
- [ ] 自动派单成功；失败可人工派单
- [ ] worker 小程序只看到本人任务
- [ ] worker 可接单、到场、完成
- [ ] operator 可改部门、退回、关闭、评价
- [ ] 评价后工作台满意度/已评价数变化
- [ ] 工单详情时间线完整
- [ ] 工单列表按状态/部门/bucket 下钻

### 数据

- [ ] 部门/位置/问题目录/人员可导入
- [ ] 默认部门唯一
- [ ] 路由规则优先级符合预期
- [ ] 历史 evaluated 无分数 = 0
- [ ] 工单总数与 workbench total 一致

### 权限与隔离

- [ ] 跨租户不可见
- [ ] 师傅不可见他人工单
- [ ] worker 不能登录 PC
- [ ] operator 不能登录小程序
- [ ] 改角色后旧 JWT 失效

### 运维

- [ ] 每日备份 + 恢复演练
- [ ] `/health`、`/health/ready`
- [ ] Nginx 访问日志、500 日志可查
- [ ] 回滚脚本/备份可用

## 5. 演示数据

见 `docs/pilot-demo-data-20261109.md`：

- `seed-pilot-demo.mjs`：生成/清理 100 条模拟工单、6 个师傅、3 个部门、6 条路由规则；
- `pilot-e2e.mjs`：一条命令跑完整闭环并自动清理。
